# Pencil Client

A Minecraft 1.21.4 Fabric client with:
- GUI opened by Right Shift
- Title: Pencil Client
- Tabs: Visual, Combat, Misc, Config, Player, Movement

## Build

1. Install Java 21
2. Run:
   ./gradlew build
3. Built jar will be in:
   build/libs/

## Open menu

Press Right Shift in Minecraft.
